# Консольное приложение «Веб-студия»

Простой учебный проект на Java. Приложение принимает заявки клиентов
на разработку сайтов и сохраняет их в файл базы данных `webstudio.db`.

## Что реализовано

- подключение к SQLite через JDBC;
- обычное подключение через `DriverManager`;
- подключение через абстрактный класс `AbstractDatabase`;
- создание таблицы;
- добавление и просмотр заявок через консольное меню.

## Как запустить

Откройте файл `src/main/java/ru/webstudio/Main.java` и нажмите **Run**
над методом `main`.

Если Maven установлен, можно запустить из терминала:

```text
mvn compile exec:java
```

## Термины простыми словами

**Интерфейс** — договор для класса. В нём написано, какие методы должны
существовать. Например, `RequestRepository` требует методы создания
таблицы, добавления и чтения заявок.

**Перегрузка** — несколько методов или конструкторов с одинаковым именем,
но разными параметрами. В `ClientRequest` есть два разных конструктора.

**Переопределение** — класс изменяет реализацию унаследованного метода.
Например, `SQLiteDatabase` переопределяет `connect()`, а `ClientRequest`
переопределяет `toString()`.

## Принципы ООП в проекте

1. **Инкапсуляция** — поля `ClientRequest` закрыты словом `private`.
2. **Наследование** — `SQLiteDatabase` наследуется от `AbstractDatabase`.
3. **Полиморфизм** — объект `SQLiteDatabase` используется через тип
   `AbstractDatabase`.
4. **Абстракция** — детали подключения скрыты за абстрактным классом,
   а работа с заявками — за интерфейсом.
